If something goes wrong

ProblemFix
Wokwi slow or queuedAsk pairs to share one simulation, or let them read the code while you demo on the projector. The free compiler can queue when 30+ people press Start at once; stagger by rows.
Library not found (Lab 4/5)Library Manager → + → type the exact name, or add a libraries.txt file with the list from the lab page.
Dashboard shows “Offline”Switch the broker selector to EMQX. If you switch, students must also change MQTT_BROKER to broker.emqx.io. If the college firewall blocks WebSockets, use your phone hotspot for the projector laptop. Students' ESP32s still work, because they connect through Wokwi's cloud.
No devices appearCheck the topic root in the sketch (navkis/ews2026) matches config.js. Ask one student to read their Serial Monitor aloud.
Internet down completelySlides work offline from the ZIP. Do the labs as a projector walkthrough, and give the site link for practice at home.

Slide numbers refer to the current deck (42 slides). Use the arrow keys, or type the number into the URL (slides.html#20).
