What you will be able to do by 4 PM

💡 Control

Drive GPIO pins, and use millis() instead of blocking delays.

⚡ React

Handle buttons with interrupts and debounce them properly.

🌡 Sense

Read analog voltages with the ADC, dim with PWM, and talk to chips over I²C.

🌐 Connect

Publish data with MQTT and control a device from a web dashboard.

🧵 Multitask

Run FreeRTOS tasks and queues — your OS course on real silicon.
